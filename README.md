# QMOOSA Cross-Chain SDK (`@qmoosa/crosschain-sdk`)

Type-Safe Client SDK, Preimage Generator, and Atomic Swap Coordinator.

## Capabilities

- **Preimage & Hashlock Generation:** Cryptographically secure 32-byte entropy and SHA-256 hashlock generation.
- **Timelock Verification:** Enforces 300-second safety margin between source and destination chains.
- **State Coordination:** Manages atomic swap lifecycle from initialization to confirmation, claim, and refund.
- **Zero External Runtime Dependencies:** Implemented with pure Node.js/Web standard APIs.
